Guardrails are code, not a policy PDF.

Limits, approvals and tool permissions are declared next to the agent itself — versioned, reviewed and tested like the rest of your system.

# illustrative
@cymonic_agent(
    name="slot_closer",
    tools=[mcp("bookings"), mcp("whatsapp")],
    guardrails=[max_discount(pct=15)],
    approval=human_over("discount"),
)
def fill_open_slots(ctx):
    slots = ctx.tools.bookings.open(within="3h")
    return ctx.offer(slots, to="waitlist")
